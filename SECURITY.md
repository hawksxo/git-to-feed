# Security Policy

## Supported Versions

We issue security updates and patches for the following supported versions of `git-to-feed`:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **`git-to-feed`** seriously. If you discover a security vulnerability (such as HMAC verification flaws, authentication bypasses, or credential leaks), please report it responsibly:

1. **Do NOT open a public GitHub Issue** for security vulnerabilities.
2. Email your report privately to the maintainers at **`losadabolivar@gmail.com`**.
3. Include detailed steps to reproduce the issue, proof-of-concept (PoC) code if available, and affected endpoints.

### What to Expect:
- **Acknowledgement**: You will receive a response within 48 hours acknowledging receipt of your report.
- **Assessment**: The core maintainers will verify the vulnerability and determine its impact.
- **Patch & Advisory**: A security patch will be developed and deployed to the `release` branch. You will be credited in the release notes unless you request anonymity.
